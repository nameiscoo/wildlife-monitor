How it connects: the camera console broadcasts each identified animal on a wildlife-cctv channel and this page listens for it. Nothing leaves the browser. Open the console and the dashboard from the same folder (via localhost or https) so they can see each other, or use the console's Open Dashboard button. The wound flag comes from a colour heuristic, so treat it as a prompt to check, not a diagnosis.
